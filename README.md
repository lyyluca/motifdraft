# MotifDraft

Turn images into cross stitch, crochet, and bead charts. Edit colors and grids, then print your pattern.

Website: [https://motifdraft.com](https://motifdraft.com)

## Features
- Image-to-chart workflows for cross stitch, crochet, and beads
- Editable colors and grids
- Pattern printing
- Free starting experience, no signup required

## How to use
1. Open https://motifdraft.com.
2. Choose pattern maker for your craft.
3. Start with an image.
4. Edit colors/grid and print pattern.
